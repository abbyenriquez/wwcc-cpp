## Description

The Lost Treasure of Pine Woods is a text-based adventure game where the player explores the woods in search of a hidden treasure. The player must find clues, collect items, solve a puzzle, and locate the treasure.


## How to Run

### Mac/Linux

```bash
./game
```

### Windows

```bash
game.exe
```

---

## How to Play

1. Enter your name.
2. Explore different locations.
3. Find the map piece and shovel.
4. Solve the puzzle in the hidden clearing.
5. Find and dig up the treasure.

If you fail the puzzle, the game ends.

---

## Features

* Multiple locations
* Inventory system
* Puzzle challenge
* Win and lose endings
* File reading from a text file
* File writing to a summary file
* Uses functions, loops, vectors, structs, and enums

---

## Output File

When the game ends, a file called **game_summary.txt** is created. It records:

* Player name
* Clues found
* Items collected
* Puzzle result
* Final result (Victory or Defeat)
